# Titanic Survival Prediction using Machine Learning

## Objective
To analyze the Titanic dataset and predict whether a passenger survived or not using Machine Learning.

## Dataset
Titanic dataset containing passenger information such as age, gender, passenger class, fare, and survival status.

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## Results
The models achieved approximately 80–81% accuracy on the test data.

## Conclusion
The models were able to predict passenger survival with good accuracy. Among the tested models, Logistic Regression and Random Forest performed slightly better than Decision Tree.
